🔒 Privacy Policy

Last updated: 29 September 2026

📌 Sabse Zaroori Baat, Seedhe Shabdon Mein

PaisaGuru ek local-first app hai. Matlab: aapki salary, kharche, goals aur settings — sab kuch sirf aapke apne browser mein (localStorage) save hota hai. Default setup mein ye data kabhi kisi server par nahi jaata, na hum ise dekh sakte hain, na koi teesra.

🗂️ Hum Kya Data Store Karte Hain (Aapke Device Par)

  • Financial data: salary, planned budget, kharche ki entries, saving goals, emergency fund status — sab localStorage mein.
  • Profile info: agar aap multi-user feature use karte hain, to naam, icon aur (optional) PIN — PIN plain text mein nahi, ek hashed form mein store hota hai, aur ye bhi sirf isi device/browser mein rehta hai.
  • Theme preference: dark/light mode ka choice bhi localStorage mein.
  • Session info: kaunsa profile abhi active hai — ye sessionStorage mein, sirf us tab ke liye (tab band karte hi clear ho jaata hai).

Ye sab kabhi kisi network request mein bahar nahi jaata — hum tracking, analytics, ya ads ka koi bhi third-party script use nahi karte.

☁️ Optional Features Jo Internet Use Karte Hain

Kuch features tabhi kaam karte hain jab app ke owner ne backend enable kiya ho (default mein OFF hota hai) — inhe use karna hamesha aapki apni choice hai:

  • Account Login / License: agar ye feature ON hai aur aap login/activate karte hain, to sirf aapka email aur license status verify karne ke liye backend server ko bheja jaata hai.
  • Cloud Backup: agar aap khud "Cloud Backup" button dabate hain, tabhi aapka poora data (months, goals, settings) encrypted connection (HTTPS) ke through backend par save hota hai — taaki aap use naye device par restore kar sakein. Ye automatic nahi hai, sirf aapke button dabane par hota hai.
  • Live Rates: app kabhi-kabhi latest FD/PPF/mutual-fund rates dikhane ke liye ek chhoti si rates file fetch karta hai — isme aapki koi personal/financial information nahi bheji jaati, sirf rates file download hoti hai.
  • Voice Input (🎤): agar aap "Bolkar Kharcha Add Karein" use karte hain, to ye aapke browser ke built-in Speech Recognition (Web Speech API) se chalta hai. Kuch browsers (jaise Chrome) audio ko process karne ke liye apni khud ki speech-service (e.g. Google) use karte hain — ye poori tarah browser vendor ki policy par depend karta hai, PaisaGuru khud koi audio store ya bheja nahi karta.

🔗 Verified Invest/Save Links

"Salah" tab mein diye gaye investment/saving links (jaise PPF, FD, mutual funds) aapko seedhe us official/verified website par le jaate hain (naye tab mein). Ek baar aap us site par chale jaayein, uski apni privacy policy लागू hoti hai — PaisaGuru uska zimmedar nahi hai.

🍪 Cookies, Ads, Tracking

PaisaGuru koi cookies, advertising SDK, ya third-party analytics/tracking script use nahi karta. Koi bhi data kisi marketing/ad company ko nahi becha ya share kiya jaata.

🗑️ Apna Data Delete Kaise Karein

  • App ke andar: Settings → 💾 Data → Saara Data Delete Karein button se sab kuch turant clear ho jaata hai.
  • Alternative: apne browser ki settings se is website ka "Site Data" / "Local Storage" clear kar dein — usse bhi sab kuch mit jaata hai.
  • Agar aapne Cloud Backup use kiya tha aur us data ko bhi delete karwana hai, to app owner se support contact ke through request karein.

👶 Bachon Ki Privacy

PaisaGuru ek general finance-tracking tool hai aur knowingly 13 saal se chhote bachon se koi data collect nahi karta.

✏️ Is Policy Mein Badlaav

Agar future mein ye policy update hoti hai, to is page ki "Last updated" date badal jaayegi. Bada koi badlaav hone par app ke andar bhi ek notice dikhaya jaayega, jahan tak mumkin ho.

📩 Sawaal Hai?

Is app ke data-handling ke baare mein koi sawaal ho to app ke Settings section mein diye gaye support contact (agar available ho) par sampark karein.
